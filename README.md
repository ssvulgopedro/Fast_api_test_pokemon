Depois de clonar, instalar as dependencias e rodar a main.py, 
é so ir no seu navegador e colar http://0.0.0.0:8000/ para testar se a api estar no ar, 
http://0.0.0.0:8000/docs ou http://0.0.0.0:8000/redoc para ver a documentação, 
e por ultimo, http://0.0.0.0:8000/pokemon/chikorita para ser redirecionando pra uma imagem da chikorita, voce pode mudar o nome pra outro pokemon.
